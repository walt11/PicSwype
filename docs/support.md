# PicSwype support

For help with PicSwype on iPhone or iPad, you can ask John Walter a question or report a problem. [Open a support request on GitHub](https://github.com/walt11/PicSwype/issues/new)

Include your PicSwype version and build number if available, your iOS version, the libraries involved, and what happened. For a matching problem, include the file type and the message shown in the queue. GitHub issues are public. Leave out private photos, server addresses, usernames, passwords, and API keys.

## Connecting a library

PicSwype starts with Apple Photos. If items are missing, check which photos and videos you’ve shared with PicSwype in iOS Settings. To add another library, open PicSwype Settings and choose **Add Immich** or **Add Synology Photos**. Once connected, tap the app title to switch libraries.

## Matching and deletion

Turn on **Link libraries** in Settings to check queued items for copies. PicSwype compares original files. A re-encoded video or an edited photo can look identical and still have different file contents. Large videos can take longer to check. If an item times out, check that its original is accessible and choose **Retry matching** in the queue.

Swiping left adds an item to the queue. Open the queue to choose which copies to delete. To keep an item you queued by mistake, use **Keep** before choosing **Delete All**.
